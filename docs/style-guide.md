# 카드 구성·문체 기준 — 초안

마케팅 실무 관점에서 계속 다듬어 갈 기준입니다. 바뀐 내용은 아래 "변경 기록"에 남깁니다.

## 기본 카드 구성 (5장 기준)

| 순서 | 역할 | 권장 템플릿 | 담는 내용 |
|---|---|---|---|
| 1 | `cover` | 표지형 | 제품명 + 핵심 메시지 한 줄 |
| 2 | `feature` | 이미지 강조형 | 가장 중요한 특징 1개 + 제품 이미지 |
| 3 | `feature` | 설명형 | 나머지 특징 2~3개 |
| 4 | `usage` | 설명형 | 사용 방법 단계 |
| 5 | `closing` | 표지형 또는 이미지 강조형 | 핵심 메시지 다시 정리 |

- 카드 수가 다르면 `feature`, `detail` 카드 수로 조절하고, 1번 표지와 마지막 마무리는 유지합니다.
- 입력 양식의 "강조 정보"는 1~2번 카드 안에 들어가게 배치합니다.
- 주의사항이 있으면 사용법 카드나 마지막 카드에 원문 그대로 짧게 넣는 것을 검토합니다.

## 문체

- 해요체를 씁니다. (예: "가볍게 발려요")
- 한 카드에는 메시지 하나만 담습니다.
- 제목은 명사형 또는 짧은 문장, 본문은 한 문장씩 끊어서 씁니다.
- 숫자·성분명·인증은 원문 표기를 그대로 씁니다. (SPF50+를 SPF 50으로 바꾸지 않음)
- 이모지와 느낌표는 쓰지 않습니다. (팀 논의 후 변경 가능)
- 제목 줄바꿈(`\n`)은 의미 단위로 끊을 때만 넣습니다. 예: "자외선 차단에\n자연스러운 톤업까지". 한 줄 글자 수 기준은 `docs/card-data-spec.md` 표를 따릅니다.

## 피해야 할 표현

- 원문보다 강한 표현으로 바꾸기: "도움을 줄 수 있어요" → "해결해요" ✗
- 과장·최상급: 최고, 유일, 완벽, 무조건
- 원문에 없는 비교: "기존 선크림보다", "다른 제품과 달리"
- 의약품처럼 보이는 표현: 치료, 재생, 염증 개선 등 (`config/caution-expressions.json` 참고)

## 주의 표현 판단 기준

`npm run validate`는 카드 문구에서 `config/caution-expressions.json`의 표현을 찾아 `[주의]`로 표시합니다. 오류가 아니라 판단할 곳 표시이고, 원문에 같은 표현이 있는지(`원문에 있음` / `원문에 없음`)를 함께 보여줍니다.

| 경우 | 판단 |
|---|---|
| 원문에 없음 | 지웁니다. 원문 표현으로 돌리거나 그 문장을 뺍니다. (내용 규칙: 원문에 없는 효능·인증을 쓰지 않음) |
| 원문에 있음 + 절대·최상급, 즉각·확정 효과, 부작용·안전성 단정 | 원문에 있어도 카드에는 쓰지 않습니다. 사실 부분만 남깁니다. 예: "최고의 밀착력" → "밀착력". 다만 '대한민국 최초'처럼 객관적 근거(출처)가 원문에 함께 있으면 원문 그대로 씁니다 |
| 원문에 있음 + 의약품 오인, 인체 유래·시술 오인, 특정인·기관 공인 | 쓰지 않습니다. 원문 자체가 금지 표현일 수 있어 결과 보고에 `[주의]`와 이유를 남겨 사람이 원문을 확인하게 합니다. 예외: 여드름·항균은 기능성 심사(보고)나 실증 근거가, '피부과 테스트 완료'는 시험 근거가 원문에 있으면 원문 그대로 씁니다 |
| 원문에 있음 + 기능성 표방, 피부·신체 변화 단정, 인증·성분 사실 오인 | 원문에 근거(기능성 심사·보고, 실증, 인증)가 적혀 있으면 원문 표현 그대로 씁니다. 근거가 없으면 쓰지 않고 이유를 남깁니다. 배합금지 원료 무첨가(無·free)와 EWG 등급을 근거로 한 표현은 근거가 있어도 쓰지 않습니다 |

- 원문 근거 예: "기능성화장품(미백) 심사 완료", "인체적용시험 결과 …", "○○ 비건 인증". 근거 문장도 `sources`에 인용합니다.
- 배합금지 원료가 아닌 성분의 무첨가(예: "설탕 무첨가")가 원문에 있으면 원문 그대로 둘 수 있습니다.
- 목록에 없어도 같은 뜻의 표현(외국어 포함)은 같은 기준으로 판단합니다. 표현 하나만이 아니라 카드 전체가 주는 인상으로 봅니다(식약처 지침 III. 주의사항 4·6).
- 근거 문서: 식약처 「화장품 표시·광고 관리 지침」(안내서-0086-07, 2025-08-14) 별표 1·2, 「화장품법 시행규칙」 별표 5 제2호, 대한화장품협회 「화장품 광고자문 기준 및 해설서」(2025). 분류마다 근거 항목은 목록의 `basis`, 근거 문서에 글자 그대로 없지만 같은 뜻으로 넓힌 표현은 `extended`에 적습니다. 문서가 개정되면 목록과 이 표를 함께 고칩니다.
