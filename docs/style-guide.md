# 카드 구성·문체 기준 — 초안

마케팅 실무 관점에서 계속 다듬어 갈 기준입니다. 바뀐 내용은 아래 "변경 기록"에 남깁니다.

## 기본 카드 구성 (5장 기준)

| 순서 | 역할 | 권장 템플릿 | 담는 내용 |
|---|---|---|---|
| 1 | `cover` | 표지형 | 제품명 + 핵심 메시지 한 줄 |
| 2 | `feature` | 이미지 강조형 | 가장 중요한 특징 1개 + 제품 이미지 |
| 3 | `feature` | 설명형 | 나머지 특징 2~3개 |
| 4 | `usage` | 설명형 | 사용 방법 단계 |
| 5 | `closing` | 표지형 또는 이미지 강조형 | 핵심 메시지 다시 정리 |

- 카드 수가 다르면 `feature`, `detail` 카드 수로 조절하고, 1번 표지와 마지막 마무리는 유지합니다.
- 입력 양식의 "강조 정보"는 1~2번 카드 안에 들어가게 배치합니다.
- 주의사항이 있으면 사용법 카드나 마지막 카드에 원문 그대로 짧게 넣는 것을 검토합니다.

## 문체

- 해요체를 씁니다. (예: "가볍게 발려요")
- 한 카드에는 메시지 하나만 담습니다.
- 제목은 명사형 또는 짧은 문장, 본문은 한 문장씩 끊어서 씁니다.
- 숫자·성분명·인증은 원문 표기를 그대로 씁니다. (SPF50+를 SPF 50으로 바꾸지 않음)
- 이모지와 느낌표는 쓰지 않습니다. (팀 논의 후 변경 가능)

## 피해야 할 표현

- 원문보다 강한 표현으로 바꾸기: "도움을 줄 수 있어요" → "해결해요" ✗
- 과장·최상급: 최고, 유일, 완벽, 무조건
- 원문에 없는 비교: "기존 선크림보다", "다른 제품과 달리"
- 의약품처럼 보이는 표현: 치료, 재생, 염증 개선 등 (`config/caution-expressions.json` 참고)
