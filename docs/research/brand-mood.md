# 브랜드 무드 (브랜드 URL + 자료 → 무드 분석 → GPT 배경, A안)

카테고리·무드를 하나씩 고르는 대신, **브랜드 공식몰 주소와 제품 자료만 넣으면** 상세페이지 무드를 읽고 GPT가 그에 맞는 카드 배경을 만드는 흐름이에요. 이용석·이규동 구두 합의(2026-11-05), 제안 이슈 #87을 이어받음.

**A안: GPT는 배경만, 글자는 코드.** 카드 글자는 전부 `cards.json`에서 출력이 얹어서 원문 근거·주의 표현·글자 수 검증을 그대로 거쳐요. GPT가 글자를 그리는 AI 디자인 카드(`npm run ai-card`)는 묶음 `브랜드`에서는 쓰지 않아요.

## 흐름

| 단계 | 누가 | 하는 일 | 결과 |
|---|---|---|---|
| 1. 자료로 채우기 (선택) | 작업실 입력 화면 → `claude -p` (Read만) | 제품 소개 PDF·이미지·글을 읽고 '제품 정보' 칸 초안을 채움. **저장하지 않음** — 사람이 원문과 대조해 고친 뒤 저장해야 `input.md`(원문)가 됨 | 입력 칸 |
| 2. 브랜드 URL | 입력 양식 `제작 조건 > 브랜드 URL` | 적고 무드를 비우면 묶음은 `브랜드` | `input.md` |
| 3. 스냅샷 | 작업실이 구성안 작업 전에 자동 (`npm run brand -- <ID>`) | 상세페이지를 한 번 열어 화면 최대 6장·글·대표 색·글꼴 저장. 같은 주소로 찍은 게 있으면 다시 안 찍음 | `brand/snapshot.json`, `shot-NN.jpg`, `page.txt` |
| 4. 무드 분석 | 구성안 작업 (Claude) | 스냅샷 화면을 보고 색 7개·분위기·사진 연출·배경 장면·근거를 정함. 스냅샷이 없거나 실패하면 제품 사진으로 (`source: product_photo`) | `cards.json` `brand_mood` |
| 5. 구성안 확인 | 사람 | 작업실 '브랜드 무드' 패널에서 화면·색·장면·근거 확인 후 승인 | |
| 6. 문구·출력 | 문구 작업 (Claude) | 지금과 같음. 브랜드 색으로 출력 | `output/png` |
| 7. GPT 배경 | 작업실이 문구 작업 뒤 자동 (`npm run ai-bg -- <ID>`) | 카드마다 `brand_mood.scene`·색·글자 면 자리로 요청 → 글자·제품 없는 배경 → 다시 출력 | `output/ai-bg/card-NN.png` |
| 7'. 채팅으로 대신 (한도일 때) | 사람 | Codex가 ChatGPT 사용량 한도에 걸리면 작업실 'AI 배경'에서 카드별 **요청문 복사** → ChatGPT 채팅에 붙여 넣기 → 받은 이미지를 **이미지 올리기**. CLI는 `npm run ai-bg -- <ID> --prompts`·`--import N <파일>`. 채팅창을 자동으로 조작하지는 않음(약관) | `output/ai-bg/card-NN.png` (`source: chat`) |
| 8. 최종 승인 | 사람 | 배경에 글자·로고가 섞였는지 눈으로 확인 (섞였으면 그 카드만 다시) | |

## 보안·법규

- **작업 실행기는 웹에 접속하지 않아요.** 스냅샷은 별도 스크립트가 찍고, 구성안 작업은 저장된 파일만 읽어요. `http(s)`만, 내 컴퓨터·사내망 주소·계정 정보가 든 주소는 막아요.
- **페이지 글은 원문이 아니에요.** 분위기 판단 자료일 뿐 카드 문구나 근거로 쓰지 않아요(`CLAUDE.md` '입력 자료 취급'). 지시문 형태 문장은 `snapshot.json` `warnings`에 남기고 따르지 않아요.
- **자료로 채우기**는 임시 폴더에 자료만 두고 Read·Glob만 허용해요. 자료에 없는 칸은 비우고, 지시문은 경고로 돌려줘요.
- 배경 요청에는 글자·로고·제품·사람·의료/시술·전후 비교·인증 마크를 금지해요. 제품은 실제 사진을 출력이 얹어요.
- 브랜드 공식 이미지·스냅샷은 **내부 시연용**이에요. 결과 보기 웹에 공개할 때는 이미지 사용 가능 여부를 따로 확인해요.

## 파일

| 파일 | 내용 |
|---|---|
| `scripts/brand-snapshot.js` | 스냅샷 (`npm run brand`) |
| `scripts/ai-bg.js` | 카드별 GPT 배경 + 다시 출력 (`npm run ai-bg`, `--card N`·`--stale`·`--no-render`, 채팅용 `--prompts`·`--import N <파일>`) |
| `scripts/lib/brand.js` | 주소 검사, `brand_mood` 검사, 브랜드 색, 배경 요청문·신선도 key |
| `scripts/lib/extract-input.js` | 자료로 채우기 (`POST /api/studio/extract`) |
| `templates/brand/*.html` | 묶음 `브랜드`: 카드 전체 배경 + 실제 제품 사진 + 반투명 글자 면 |
| `config/templates.json` | `_catalog.브랜드`, `_designs.브랜드` (글자 수 기준은 calibrate로 잼) |

## 평가

- 평가 입력에는 브랜드 URL이 없어서 v1 기준선(기본 묶음)은 바뀌지 않아요. 브랜드 무드는 비교판으로 따로 돌려요.
- 재현은 저장한 스냅샷으로만 해요(페이지는 바뀔 수 있음). GPT 배경은 같은 요청이어도 매번 달라서 배경 파일을 결과와 함께 보관해요.
