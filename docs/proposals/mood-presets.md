# 제안: 무드 프리셋 — 브랜드 무드 · 제품 유형 · 인증 배지

- 상태: 제안·초안 (2026-10-21, 이용석). 결정 아님
- 이슈: #53 (디자인 묶음). 관련 [글 무드·제품 색 무드](mood-proposal.md) (#39), [디자인 레퍼런스 분석](../research/design-reference-review.md), [카드 색](../card-color.md) (#38)
- 목표 모양: [달바 퍼플 B2 시안](../research/dalba-purple-redesign/README.md) 8장

## 목표

'라일락' 같은 디자인 한 벌을 늘려 가는 게 아니라, 화장품 브랜드가 흔히 갖는 무드를 미리 만들어 두고 사람이 고르면 그 무드대로 카드가 나오게 한다.
예: 달바는 프리미엄 비건 브랜드 → `프리미엄` + `선케어` + 배지 `비건` → B2 시안 모양.

브랜드를 따로 등록하지 않는다. 고르는 건 무드 이름뿐이고, 색은 제품 사진에서(#38), 내용은 원문에서 온다.

## 세 가지를 따로 고름

| 고르는 것 | 정하는 것 | 누가 | 달바 예 |
|---|---|---|---|
| 브랜드 무드 | 글꼴·여백·배치·제품 사진 크기·색 쓰는 법·말투 | 사람 (비우면 Claude가 원문 신호로 추천, 구성안 확인 때 바꿀 수 있음) | 프리미엄 |
| 제품 유형 | 카드에 꼭 넣을 정보·사용법 카드 모양 | 입력 양식 '카테고리' | 선케어 |
| 인증 배지 | 표지·마무리 배지 | 원문 인용이 있을 때만 자동으로 켜짐 | 비건(V-LABEL), 기능성 3중, 저자극 시험 |

- 색은 고르지 않음. 제품 색(#38)이 색 값을 정하고, 무드는 그 색을 어떻게 쓰는지만 정함
- 무드를 안 고르면 지금 기본 템플릿 그대로
- 지금 '라일락'은 `프리미엄` × 달바 보라색. 이름을 무드 이름으로 바꾸면 그대로 첫 프리셋이 됨

## 1. 브랜드 무드 6개

[디자인 레퍼런스 분석](../research/design-reference-review.md)의 방향 3개(프리미엄·더마·내추럴)에 클린·비건, 트렌디·컬러, 미니멀·모던을 더함. 선케어는 무드가 아니라 제품 유형으로 둠 (분석 문서와 같음).

| 무드 | 이런 브랜드 | 글꼴 | 색 쓰는 법 | 배치·여백 | 제품 사진 | 말투 |
|---|---|---|---|---|---|---|
| 프리미엄 | 고급 원료·브랜드 스토리 | 세리프 제목 가늘게, 작은 영문 머리말 | 제품 색 옅은 단색 그라데이션, 강조는 같은 색 진하게 | 여백 많이, 가는 선 하나, 반반 나눈 면 | 크게, 살짝 기울임, 바닥 그림자 | 짧고 절제, 명사형 제목 |
| 더마·전문 | 시험·수치·성분 근거가 많음 | 산세리프 굵게, 숫자 가장 크게 | 흰 바탕 + 제품 색 한 가지(선·숫자) | 격자, 표·구분선 | 오른쪽 중간 크기, 정면 | 사실 먼저, 수치를 제목 위로 |
| 클린·비건 | 성분 투명성·친환경·인증 | 둥근 산세리프, 소문자 영문 | 오트·베이지 바탕 + 제품 색 옅게 | 종이 느낌 면, 배지 자리 | 중간, 자연광 그림자 | 담백한 해요체 |
| 내추럴·데일리 | 순한 사용감·매일 쓰는 기초 | 부드러운 산세리프 굵게 | 제품 색 파스텔 블록 + 흰색 | 색 블록 / 흰 영역 2단, 키워드 칩 | 가장 크게, 블록 경계 넘김 | 부드러운 해요체 |
| 트렌디·컬러 | 색조·젊은 타깃·한정판 | 굵은 산세리프, 큰 구어체 제목 | 제품 색 쨍하게 + 보색 포인트 | 대각선·큰 글자, 장마다 색 번갈아 | 여러 개 반복 배치 | 짧은 구어체, 키워드 |
| 미니멀·모던 | 무채색 패키지·단순 성분 | 산세리프 보통 굵기, 작은 글자 | 흰·회색 + 제품 색 아주 조금 | 정렬 엄격, 장식 없음 | 가운데 작게 | 짧은 단정문 |

무드별로 피할 것

| 무드 | 피할 것 |
|---|---|
| 프리미엄 | 금색·대리석 소품, 원문에 없는 '럭셔리' 류 |
| 더마·전문 | 원문에 없는 시험·수치·'피부과', 십자·알약 아이콘 |
| 클린·비건 | 인증 근거 없는 '비건'·'무해' |
| 내추럴·데일리 | 이모지·느낌표, 원문 없는 '저자극'·'순한' |
| 트렌디·컬러 | 원문 없는 '품절'·'대란' 류 |
| 미니멀·모던 | 장식·그라데이션 과다 |

비웠을 때 추천 신호 (원문 인용으로 근거를 남김)

| 무드 | 원문 신호 |
|---|---|
| 프리미엄 | 합니다체, 감각 형용사("선사합니다"), 원료 산지·고급 원료 |
| 더마·전문 | 기능성 심사·인체적용시험·수치(SPF, %, 기간) 문장이 많음 |
| 클린·비건 | 비건·EWG·무첨가 등 인증·성분 표기 |
| 내추럴·데일리 | 해요체, "매일·부담 없이·가볍게", 사용감 중심 |
| 트렌디·컬러 | 색상명·호수, 신조어·해시태그 |
| 미니멀·모던 | 짧은 문장, 성분 수가 적음, 꾸밈말 거의 없음 |

## 2. 제품 유형 6개

| 유형 | 꼭 넣을 정보 (원문에 있을 때) | 사용법 카드 |
|---|---|---|
| 선케어 | SPF·PA, 기능성, 사용량, 덧바르기 | 양·부위·순서 |
| 기초 (토너·세럼·크림) | 핵심 성분, 제형, 피부 고민 | 단계 순서 |
| 클렌징 | 제형, 세정 방식, 사용감 | 양·문지르는 시간·헹굼 |
| 마스크·팩 | 사용 시간, 주기 | 붙이는 시간·마무리 |
| 메이크업 | 색상·호수, 지속력, 마무리감 | 도구·순서 |
| 바디·헤어 | 향, 사용 부위, 제형 | 양·부위 |

## 3. 인증 배지

원문 인용이 있을 때만 켜지고, 문구는 원문 표현 그대로. 없는 인증은 무드와 상관없이 못 씀 (`CLAUDE.md` 내용 규칙이 무드보다 위).

- 비건 인증, 기능성(미백·주름·자외선), 저자극·인체적용시험 완료, 무향, 유기농 인증, 리필·친환경 용기

## 4. 달바 적용 예

`프리미엄` + `선케어` + 배지(비건·기능성 3중·저자극 시험) → B2 시안

| 장 | 모양 |
|---|---|
| 1 표지 | 큰 제품 기울여 + 2줄 제목, SPF 배지 |
| 2 특징 | 제품 반쪽 + 기능성 3중 번호 목록 |
| 3 특징 | 사용감 3줄 + 제품 반쪽 (좌우 번갈아) |
| 4 사용법 | STEP + 부위별 양 |
| 5 마무리 | 가운데 한 줄 + 인증 배지 |

## 5. 진행 순서 (안)

1. `프리미엄` 하나로 시작 — 지금 라일락 구현(#53 브랜치)의 이름을 무드 이름으로, 고르면 제품 색이 같이 켜지게
2. 달바 퍼플로 B2 모양까지 맞추고 출력·검증
3. 더마·전문 → 내추럴·데일리 → 나머지 순서로 하나씩 추가. 무드마다 다른 제품 하나로 확인

## 6. 같이 정할 것 (이규동)

- 입력 칸: '디자인'을 '무드'로 바꿀지, 제품 유형·배지 칸 추가 (입력 양식 공동)
- 무드별 말투: 지금은 해요체 고정 → 무드별로 풀면 규칙 버전 v2 (A5 비교)
- 카드 데이터: 이미지형 카드 항목 목록, 부위별 사용량, 배지 칸 → 규격 변경이라 두 사람 승인
- 무드 개수: 6개를 다 만들지, 3개로 먼저 시연할지 (10.28 시연 범위)
