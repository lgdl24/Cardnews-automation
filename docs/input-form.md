# 입력 양식

새 제품을 만들 때 이 파일을 `products/<제품ID>/input.md`로 복사해서 채웁니다.
이미지는 `products/<제품ID>/images/`에 넣습니다.
웹(서비스 모드)에서는 입력 폼이 이 형식 그대로 `input.md`를 만듭니다. 양식 항목을 바꾸면 웹 입력 폼(W3)도 함께 고칩니다.

- `#`(큰 제목)과 `##`(항목 이름)은 지우거나 바꾸지 않습니다. 검사 프로그램이 이 이름으로 항목을 찾습니다.
- **필수** 표시 항목이 비어 있으면 제작이 진행되지 않습니다.
- `# 제품 정보` 아래 내용이 "원문"입니다. 카드 문구는 이 범위 안에서만 만들어집니다.

---

```markdown
# 제품 정보

## 제품명
(필수) 예: 데일리 톤업 선크림

## 브랜드
(선택)

## 카테고리
(선택) 예: 선케어

## 제품 설명
(필수) 제품 소개 문단을 그대로 붙여 넣습니다.

## 주요 특징
(필수) 한 줄에 하나씩
- 특징 1
- 특징 2

## 사용 방법
(필수)

## 주의사항
(선택) 제품에 표기된 사용상 주의사항

## 이미지
(필수) 한 줄에 하나씩: 파일명 | 설명 | 출처 | 사용 가능 여부(가능/불가/확인 중)
- main.png | 제품 단독 컷 | 직접 촬영 | 가능

# 제작 조건

## 콘텐츠 목적
(필수) 예: 신제품 소개, 사용법 안내

## 강조 정보
(선택) 꼭 들어가야 할 정보

## 카드 수
(필수) 숫자만. 예: 5
```
