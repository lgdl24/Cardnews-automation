UI/UX Pro Max를 사용해서 우리 카드뉴스 웹 작업실의 디자인과 UX를 개선해줘.

먼저 `/Users/lee/git/Cardnews-automation/docs/web-design-claude-brief.md`와 프로젝트의 `CLAUDE.md`, `AGENTS.md`, `docs/handoff.md`를 읽어. 스킬은 `/Users/lee/git/Cardnews-automation/.claude/skills/ui-ux-pro-max/`에 설치되어 있어.

기존 실험 폴더에 미커밋 변경이 많으니 보존하고, 최신 main을 확인한 뒤 별도 이슈·브랜치·worktree에서 작업해. 설치한 스킬과 인계 문서는 아직 로컬 변경이므로 필요한 준비 파일만 새 작업 폴더에 선택적으로 가져와.

이번에는 1차 범위인 웹 UI 개편을 실제로 구현해줘. 깔끔하고 젊은 산세리프, 밝게/어둡게, 카드 미리보기 중심 화면, 간결한 입력, 명확한 승인·수정 동선, 실제 생성 진행·대기·실패 안내를 완성해. 현재 React·TypeScript·CSS 구성과 제품 데이터·카드 디자인 규칙은 유지해. 원문 근거·실제 평가 결과·승인 상태도 보존해.

웹 개편을 검증한 뒤 인스타 수동 게시 패널의 구체적인 후속 설계를 제안해줘. 현재 인스타 코드는 별도 개발 브랜치이고, 웹 게시·캡션 수정·예약 범위는 아직 결정 전이야. 후속 설계를 이미 승인된 기능으로 취급하지 말고, 실제 게시나 프로필 변경은 실행하지 마.

사소한 디자인 결정은 스스로 하면서 작은 단위로 구현·검증·인수인계를 남겨줘. 완료 후 바뀐 화면과 검증 결과를 보여주고, 다음 구현 범위에서 결정이 필요한 내용만 정리해줘.
