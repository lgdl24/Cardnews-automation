# 디자인 묶음 미리보기

`config/templates.json`의 디자인 묶음(`_designs` + 설명 `_catalog`, #74)마다 같은 가상 제품(카모마일 순한 클렌징 오일, 시연용 가상 브랜드·직접 만든 사진)으로 출력한 카드 5장을 한 장에 모은 그림이에요. `_catalog.<묶음>.preview`가 이 파일을 가리켜요.

| 묶음 (입력 `무드` 값) | 이름 | 폴더 | 원본 시안 |
|---|---|---|---|
| `기본` | 기본 | `templates/*.html` | 2026-10-27 다시 디자인: 화장품 진열장 아치 모양 (미리보기 없음) |
| `프리미엄` | 프리미엄 | `templates/premium/` | 이용석 라일락 → 프리미엄 (#53·#65) |
| `타이포` | 큰 타이포 | `templates/typo/` | GPT 시안 10 '블루 타이프' |
| `팝` | 팝 컬러블록 | `templates/pop/` | GPT 시안 06 '듀 팝' |
| `연출` | 위쪽 연출 띠 | `templates/band/` | GPT 시안 02 '블루 나이트' |

- 시안 이미지·명세·제품 조사표는 실제 브랜드 제품을 참고한 **팀 내부 자료**라 저장소에 올리지 않아요 (이규동 PC). 시안의 색·배치·역할별 차이만 템플릿으로 옮겼고, 실제 브랜드 이름·로고·패키지는 쓰지 않았어요.
- **시안 충실도 (#74):** 새 묶음 셋은 시안을 1080px로 잘라 좌표·글자 크기·색을 재고 그대로 옮겼어요. 같은 문구로 시안과 우리 출력을 나란히 놓고 비교하며 맞췄어요.
  - **색:** 묶음 고유색 `_designs.<묶음>._theme.color`(시안에서 뽑은 색)를 쓰고, 카드 색 기본값은 `기본`(= 고유색)이에요. `제품 색`을 고르면 고유색 대신 제품 색이 들어가 시안과 달라져요. 큰 글자만 있는 색 짝은 `_theme.contrast`로 대비 3.0까지 허용해요(팝 코랄 위 흰 글자 등).
  - **사진 자리:** 입력 이미지의 용도(`제품`·`제형`·`배경`, [input-form.md](../input-form.md))에 따라 템플릿이 자리를 채워요. 타이포·팝 특징 카드는 `제형` 사진(크림 자국·젤)을, 연출 띠 위쪽은 `배경` 사진을 써요. 없으면 제품 사진으로, 연출 띠는 스튜디오 무대(짙은 파랑 벽·바닥 경계·유리 받침)로 대신해요. 사진 흉내(빛 번짐·흐림)는 쓰지 않고, 아래 면으로 번지는 그라데이션도 배경 사진이 있을 때만 써요.
  - **배치 고정:** `tests/design-fidelity.test.js`가 표지·특징·사용법 카드의 주요 요소 위치·크기·색을 `tests/fixtures/design-fidelity.json` 기준값(시안 실측)과 비교해요. 템플릿을 고쳐 14px 넘게 움직이거나 색이 바뀌면 실패해요. 시안을 바꿀 때만 기준값을 고쳐요.
  - **글자 수:** `node scripts/calibrate.js --design <묶음>`으로 잰 값에 맞췄어요(`_measured`). 큰 제목은 줄마다 폭에 맞춰 커지고, 최소 크기로도 안 들어가면 단어 단위로 줄바꿈해요. 글자 칸끼리 겹치면 출력 경고·calibrate 실패예요.
- 미리보기 다시 만들기: 각 무드로 가상 제품을 `npm run render` → 카드 5장을 360px로 줄여 가로로 붙임. 묶음 글자 수 기준에 맞게 문구 줄바꿈만 고쳐 출력해요 (2026-10-27 시안 충실도 재구성 후 다시 만듦).
