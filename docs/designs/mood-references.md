# 템플릿 레퍼런스 (`config/mood-references.json`)

비슷한 무드의 뷰티 카드뉴스 템플릿을 레퍼런스로 모아 둔 목록이에요. **사용자가 고르는 카테고리가 아니에요.** 입력은 그대로 브랜드 URL과 제품 자료뿐이고, 구성안 작업에서 Claude가 브랜드 페이지 분위기와 가까운 레퍼런스를 찾아 참고해요.

## 흐름

```
브랜드 URL → 상세페이지 스냅샷 → 분위기 읽기(차분·여백·세리프 …)
          → 레퍼런스 목록에서 mood 단어가 가까운 1~2개 찾기
          → brand_mood: 색은 브랜드 페이지에서, 장면·사진 연출·색 쓰는 법은 레퍼런스를 참고
          → GPT 배경 + 코드가 글자를 얹음
```

- 색 값(`palette`)은 항상 브랜드 페이지의 실제 색이에요. 레퍼런스의 `color_usage`는 그 색을 **어디에 어떻게** 쓰는지만 참고해요.
- 스냅샷이 없으면 제품 사진 분위기로 가까운 레퍼런스를 찾아요.
- 참고한 레퍼런스는 `brand_mood.evidence`에 "레퍼런스 <id>"로 남겨요.
- `layout`(배치)은 지금 브랜드 템플릿이 하나라 기록만 해요. 레퍼런스가 쌓여 배치 차이가 반복되면 템플릿 변형을 만들 때 근거로 써요. `in_repo`는 이미 디자인 묶음으로 옮긴 레퍼런스예요.

## 왜 이미지가 아니라 특징 글인가

- 핀터레스트·비핸스 이미지는 대부분 다른 브랜드의 광고물이에요. 저장소에 넣거나 GPT에 참고 이미지로 주면 남의 디자인을 베낀 결과가 나올 수 있어요.
- 핀터레스트는 자동 수집을 막고 있고, 우리 프로젝트도 크롤링을 범위에서 뺐어요.
- GPT는 참고 이미지를 받으면 글자·로고까지 따라 그리기 쉬워요. 우리는 GPT가 배경만 그리고 글자는 코드가 얹어요(A안).

## 레퍼런스 한 개의 모양

| 칸 | 내용 |
|---|---|
| `id` | 영문 소문자·숫자·하이픈 |
| `title` | 보드·작품 이름 |
| `source` | `kind`(pinterest·behance·template-site·in-house), `url`(내부 참고, 없으면 null), `seen_at` |
| `mood` | 분위기 단어 3~6개. 브랜드 페이지와 견줄 말 (예: 차분, 여백, 세리프, 발랄) |
| `layout` · `type` | 배치와 글꼴 느낌 |
| `color_usage` | 색을 쓰는 방식 (배경·글자·주색의 역할). 색 값은 예시일 뿐 |
| `photo_style` · `scene` | 사진 연출, GPT 배경 장면(영어, 배경만) |
| `avoid` | 이 레퍼런스를 따라 할 때 피할 것 |
| `in_repo` | 이미 옮긴 디자인 묶음 이름, 없으면 null |

## 레퍼런스 추가하는 법

1. 핀터레스트 보드 등에서 비슷한 무드의 뷰티 카드뉴스를 사람이 골라요. 보드는 팀 내부 참고용이에요.
2. 이미지·글자·로고·패키지는 저장소에 넣지 않아요.
3. 위 모양대로 `references`에 한 개씩 추가해요. `mood` 단어는 브랜드 페이지를 볼 때 쓸 말로 적어요.
4. `npm test`의 레퍼런스 검사가 형식, 장면에 글자·제품·사람·의료 단어가 없는지, `in_repo` 묶음 이름이 있는지 봐요.
