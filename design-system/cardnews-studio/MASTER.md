# Cardnews Studio — 웹 디자인 시스템 (MASTER)

작성: 2026-11-17 · Claude Code · 브랜치 `feat/web-studio-redesign`
적용 범위: `web/` 결과 보기·제작 작업실 화면. **카드뉴스 PNG(템플릿·제품색·AI 카드)와는 무관**하다. 웹 테마를 바꿔도 카드 이미지·승인 문구·제품 사진은 바뀌지 않는다.

## 1. 제품 정의와 방향

- 정체성: 뷰티 카드뉴스를 **제작·검토·게시하는 작업실**. 쇼핑몰·홍보 랜딩이 아니다. 카드 이미지가 주인공이고, 작업 상태와 다음 행동이 가장 먼저 보여야 한다.
- 스타일: **Flat + 마이크로 인터랙션, Minimal/Swiss 정렬** (UI/UX Pro Max `product: Productivity Tool` 추천 중 채택). 그림자 대신 1px 경계·면 색 차이로 계층을 만든다. 그라데이션·입체 장식·세리프 없음.
- 밀도: 중간(작업 도구). 4px 단위 간격, 화면당 주 행동 1개.

### 검색 결과 중 채택하지 않은 것과 이유

| 추천 | 판단 |
|---|---|
| `--design-system` 패턴 "Product Demo + Features"(히어로·영상·CTA) | 랜딩용. 작업실 정보 구조와 맞지 않아 제외 |
| 색 Teal `#0D9488` + 주황 CTA | 카드 제품색(초록·주황 계열 제품)과 혼동. 포인트색 1개 원칙과 충돌해 제외 |
| 서체 Plus Jakarta Sans / Outfit + Work Sans | 한글 글리프 없음. 영문만 다른 서체가 되면 한국어 UI의 혼용 위계가 깨지고 추가 로딩이 생김 → **Pretendard 단일 서체** 유지 |
| UX: 단계 표시(Progress Indicators), 긴 내용 말줄임, 줄 길이 65~75자 | 채택 |
| React 19: 비동기 상태는 transition, 무거운 초기값은 lazy state | 채택(입력 임시 저장 복원 등) |

## 2. 서체

- `Pretendard Variable`(동적 서브셋, 이미 의존성) 하나로 한글·영문·숫자를 모두 쓴다. 대체: `-apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif`.
- 젊고 깔끔한 인상: 굵기 400/500/600/700만, 제목 자간 `-0.025em`, 본문 `-0.01em`, 숫자는 `tabular-nums`(경과 시간·개수).
- 크기(px): 12 보조 최소 · 13 보조 · 14 UI 기본 · 15 본문 · 17 섹션 제목 · 20 카드 제목 · 26 페이지 제목(모바일 22). **12px 미만 금지.** 영문 대문자 장식 라벨(`CREATIVE STUDIO` 등)은 쓰지 않고 한국어 라벨을 쓴다.
- 줄 높이: 본문 1.6, 제목 1.3. 긴 한국어는 `word-break: keep-all` + `overflow-wrap: anywhere`.

## 3. 색 토큰 (`web/src/styles/global.css`)

포인트색은 **인디고-바이올렛 하나**. 상태색 6종은 배경+글자 쌍으로만 쓰고 항상 글자·점·아이콘을 함께 표시해 색만으로 구분하지 않는다. GLOWIF 베리·블러시는 후보로만 남기고 확정하지 않았다(바꾸려면 `--accent*` 토큰만 교체).

| 토큰 | 밝게 | 어둡게 | 용도·대비 |
|---|---|---|---|
| `--bg` | `#F6F7F9` | `#0E1014` | 캔버스 |
| `--surface` | `#FFFFFF` | `#16191F` | 카드·패널 |
| `--surface-2` | `#F1F3F6` | `#1D2129` | 보조 면·입력 비활성 |
| `--surface-3` | `#E9ECF1` | `#252A33` | 눌림·호버 |
| `--line` / `--line-strong` | `#E3E6EB` / `#CDD2DA` | `#2A2F39` / `#3A404C` | 경계 |
| `--line-input` | `#8D94A1` | `#5E6676` | 입력 경계(3:1 이상) |
| `--text` | `#15181E` | `#ECEEF2` | 본문 16.6:1 / 16.4:1 |
| `--text-2` | `#5B6372` | `#A3AAB8` | 보조 6.0:1 / 7.5:1 |
| `--accent` | `#5446E8` | `#8F87FF` | 주 행동. 위 글자 `--on-accent` 흰색 6.1:1 / 어두운 글자 6.4:1 |
| `--accent-soft` / `--accent-soft-fg` | `#EEEDFE` / `#4337D6` | `#26234A` / `#BDB8FF` | 선택 상태 6.6:1 / 8.1:1 |

상태(배경/글자, 모두 4.5:1 이상 확인):

| 상태 | 뜻 | 밝게 | 어둡게 |
|---|---|---|---|
| `neutral` | 입력·구성안 대기 | `#EEF0F4`/`#4B5363` | `#232832`/`#C2C8D3` |
| `running` | 작업 중 | `#E8F1FF`/`#1F5BC4` | `#172A47`/`#8DB8FF` |
| `queued` | 대기열 | `#FFF4DB`/`#8A5300` | `#3A2C12`/`#F2C46B` |
| `review` | 사람 검토 필요 | `#F0EDFF`/`#5233D6` | `#2A2450`/`#C2B8FF` |
| `done` | 승인 완료 | `#E6F6EE`/`#17734A` | `#12342A`/`#7ED9AE` |
| `failed` | 작업 실패 | `#FDECEC`/`#C1272D` | `#3D1A1E`/`#FF9EA4` |

기존 화면이 쓰던 `--color-*`, `--stage-*` 변수는 위 토큰을 가리키는 별칭으로 유지한다(평가·비교·라이브러리 화면 호환).

## 4. 간격·모양·움직임

- 간격: 4·8·12·16·20·24·32·40·56px. 페이지 좌우 여백 40/24/16px(데스크톱/태블릿/모바일).
- 모서리: 컨트롤 8px, 패널·카드 12px, 대화상자 16px, 배지 999px. 카드 이미지 썸네일 8px.
- 그림자: 기본 없음. 떠 있는 것(고정 행동 막대·대화상자)만 `--shadow-float`.
- 움직임: 150ms(호버·선택) / 200ms(펼침). `prefers-reduced-motion`이면 전환을 끄고 회전을 늦춘다. 진행 표시는 회전 1개와 실제 단계 목록만 쓰고 **퍼센트·예상 시간·가짜 진행 막대는 쓰지 않는다.**

## 5. 컴포넌트 규칙

| 컴포넌트 | 규칙 |
|---|---|
| 버튼 | 높이 40px(작게 32px, 모바일 44px). `btn-primary`는 화면당 1개. 비활성 버튼 옆에는 이유 문구를 둔다. |
| 상태 배지 `StatusPill` | 점 + 한국어 상태. 작업 중은 점이 천천히 깜빡임(모션 감소 시 정지). |
| 단계 표시 `Stepper` | 입력 → 구성안 검토 → 카드 만들기 → 카드 검토 → 승인·내보내기. 완료 ✓, 현재, 진행 중(회전), 실패(✕) 4상태. |
| 결정 패널 | 지금 할 일 한 문장 + 그 단계의 주 행동 버튼. 작업 중이면 진행 패널, 실패면 원인·다시 하는 방법. |
| 진행 패널 | 서버 진행 기록의 실제 단계·경과 시간·마지막 활동 시각·대기 순서. 실패 코드는 사람이 읽는 설명과 다음 행동으로 바꿔 보여준다. |
| 카드 검토 | 썸네일 필름 스트립(1~N) + 큰 미리보기 + 문구·원문 근거. ←/→ 이동, 전체 흐름 보기 전환. |
| 접기 `details` | 디자인 묶음·브랜드 무드·AI/피그마 도구·검증 상세·제작 기록. 실행 중·실패·주의가 있으면 열린 상태로 시작. |
| 입력 폼 | 필수/선택 표시, 선택 항목은 그룹 끝 '선택 항목'으로 접기, 제출 시 오류 요약 + 필드 옆 오류, 입력 임시 저장(이미지 제외)·이탈 경고. |

## 6. 반응형·접근성 확인 기준

- 375 / 768 / 1024 / 1440px, 밝게/어둡게. 가로 스크롤 없음. 모바일에서 검토 행동 막대는 화면 하단 고정.
- 키보드: 건너뛰기 링크, 모든 행동 Tab 도달, 포커스 링 2px `--accent` + 2px 간격, 대화상자 포커스 이동·Esc.
- 아이콘은 `web/src/components/Icon.tsx`의 SVG만 쓴다(이모지 아이콘 금지). 장식 아이콘은 `aria-hidden`.
- 상태 변화는 `role="status"`/`aria-live="polite"`, 실패는 `role="alert"`.
