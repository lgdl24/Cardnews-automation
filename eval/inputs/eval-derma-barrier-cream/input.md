# 제품 정보

## 제품명
세라 7 배리어 크림

## 브랜드
샘플랩 더마 (평가용 가상 브랜드)

## 카테고리
스킨케어 · 크림

## 제품 설명
세라마이드 NP 1%와 판테놀 5%를 담은 보습 크림입니다. 건조한 피부를 가진 20명을 대상으로 한 인체적용시험에서 사용 직후 피부 수분량 변화를 확인했습니다(시험 기관: 가상피부연구소, 2026.06, 개인차 있음). 향료와 색소를 넣지 않은 처방입니다.

## 주요 특징
- 세라마이드 NP 1% 함유
- 판테놀 5% 함유
- 인체적용시험으로 사용 직후 피부 수분량 변화 확인 (20명, 개인차 있음)
- 향료와 색소를 넣지 않은 처방
- 50ml 에어리스 펌프 용기

## 사용 방법
세안 후 토너 다음 단계에서 펌프 1~2회 분량을 얼굴 전체에 펴 바릅니다. 건조한 부위에는 한 번 더 덧바릅니다.

## 주의사항
화장품 사용 시 또는 사용 후 직사광선에 의하여 사용 부위가 붉은 반점, 부어오름 또는 가려움증 등의 이상 증상이나 부작용이 있는 경우 전문의 등과 상담할 것. 상처가 있는 부위 등에는 사용을 자제할 것.
