# 제품 정보

## 제품명
카모마일 순한 클렌징 오일

## 브랜드
샘플랩 내추럴 (평가용 가상 브랜드)

## 카테고리
클렌징 · 오일

## 제품 설명
카모마일꽃추출물을 담은 순한 클렌징 오일이에요. 물과 만나면 우유처럼 뽀얗게 변해서 미온수로 가볍게 헹궈져요. 세안 후에도 피부가 땅기지 않도록 해바라기씨오일을 더했어요.

## 주요 특징
- 카모마일꽃추출물 함유
- 물과 만나면 유화되어 미온수로 헹궈지는 오일 제형
- 해바라기씨오일 함유
- 워터프루프 제품은 두 번 세안을 권장해요
- 200ml 펌프 용기

## 사용 방법
마른 손과 마른 얼굴에 2~3번 펌프해 부드럽게 마사지해요. 물을 조금 묻혀 뽀얗게 변하면 미온수로 헹궈요. 필요하면 폼클렌저로 한 번 더 세안해요.

## 주의사항
화장품 사용 시 또는 사용 후 직사광선에 의하여 사용 부위가 붉은 반점, 부어오름 또는 가려움증 등의 이상 증상이나 부작용이 있는 경우 전문의 등과 상담할 것. 눈에 들어갔을 때에는 즉시 씻어낼 것.
