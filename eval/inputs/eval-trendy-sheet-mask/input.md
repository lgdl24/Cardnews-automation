# 제품 정보

## 제품명
글로우 팝 비타 시트 마스크

## 브랜드
샘플랩 팝 (평가용 가상 브랜드)

## 카테고리
마스크팩 · 시트 마스크

## 제품 설명
바쁜 아침 10분이면 끝! 비타민 C 유도체(아스코빌글루코사이드)와 히알루론산을 담은 시트 마스크예요. 얇은 텐셀 시트가 얼굴에 착 붙어서 움직여도 잘 안 떨어져요. #아침마스크 #10분케어

## 주요 특징
- 비타민 C 유도체(아스코빌글루코사이드) 함유
- 히알루론산 함유
- 얇은 텐셀 소재 시트
- 1매당 에센스 25ml
- 5매입

## 사용 방법
세안 후 토너로 결을 정돈하고 시트를 얼굴에 맞게 붙여요. 10~15분 뒤 떼어 내고 남은 에센스를 가볍게 두드려 흡수시켜요. 시트는 한 번만 사용해요.

## 주의사항
화장품 사용 시 또는 사용 후 직사광선에 의하여 사용 부위가 붉은 반점, 부어오름 또는 가려움증 등의 이상 증상이나 부작용이 있는 경우 전문의 등과 상담할 것. 상처가 있는 부위 등에는 사용을 자제할 것.
